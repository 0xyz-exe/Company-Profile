## Features

- **Company Portfolio**: Interactive presentation of industrial packaging products and specifications.
- **Product Gallery**: High-resolution gallery for cups, bottles, carton boxes, and shrink labels.
- **Responsive Architecture**: Fluid display across desktop, tablet, and mobile devices.
- **Direct Business Inquiries**: Integrated communication links for wholesale orders and quotations.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/0xyz-exe/Company-Profile.git
cd Company-Profile
npm install
npm run dev
```
